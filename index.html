Version 2.5.0
May 2026
  • Full Inventory Check feature with two modes
  • Scan Mode: scan items physically, app marks each as checked
  • Manual Count: enter actual qty for each stock entry by hand
  • Auto-save check progress — resume if app is closed mid-check
  • Resume banner appears at top of Stock Check tab
  • Duplicate scan handling: prompts Mark Again or Skip
  • Check summary screen shows all discrepancies before applying
  • Three actions on summary: Continue, Flag, Confirm
  • Flag: logs discrepancies but does not change stock
  • Confirm: applies adjustments and updates inventory
  • Stock Check tab in Reports shows full history
  • Tap any past check to view its full discrepancy details
  • Before/after numbers stored in check log for tracing
  • Inventory checks included in CSV export and import
  • Clear All Data now clears activity log and check history too

  • Activity Log search and date filter (Today/Week/Month)
  • Activity type filter chips (Sales, Added, Updates, Markdown, Manual)
  • Edit and delete activity log entries
  • Undo button on activity log deletion
